# TODAMOON V2 Mobile App

This repository contains the mobile application for **TODAMOON V2**, a system designed to help drivers and passengers monitor queues, manage tricycle operations, and streamline terminal management.

---

## 📱 Features

- **Driver App**  
  - Login/Signup with Firebase Authentication  
  - Queue management (join/exit queue)  
  - Profile management (personal + tricycle details)  
  - QR code integration for entrance/exit  

- **Passenger App**  
  - View real-time queue status  
  - Book or monitor available tricycles  
  - QR-based check-in/check-out  

- **Shared**  
  - Secure data handling with Firestore  
  - Firebase Storage for profile/tricycle images  
  - Integration with TODAMOON hardware scanners  

---

## 🛠️ Tech Stack

- **Frontend:** Java / Android Studio (or React Native/Flutter if applicable)  
- **Backend:** Firebase (Auth, Firestore, Storage)  
- **Tools:** GitHub, Android Studio
